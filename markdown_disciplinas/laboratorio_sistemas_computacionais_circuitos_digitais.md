## Ementa

Metodologia de projeto de sistemas digitais. Técnicas de projeto utilizando ferramentas de síntese de sistemas digitais. Estudo de linguagem de descrição de hardware. Projeto e implementação de circuitos combinacionais. Projeto e implementação de circuitos sequenciais. Projeto e implementação de circuitos aritméticos e de máquinas de estados finitos.

### Tópicos

- Introdução ao curso: visão geral da unidade curricular, apresentação do sistema de avaliação e introdução sobre a tecnologia que emprega o FPGA
- Projeto básico para familiarização do desenvolvimento de projetos esquemáticos usando o software Quartus
- Projeto decodificador BCD para display 7 segmentos
- Projetos: contador sequencial crescente assíncrono e outro síncrono
- Projeto: filtro digital
- Projetos: contador sequencial crescente/decrescente assíncrono
- Projetos: divisor de frequência e multiplexador
- Introdução a uma ULA e seu projeto básico
- Máquina de estados para um contador crescente/decrescente
- Introdução à linguagem de descrição de hardware – Verilog Parte 1. Projeto básico para familiarização usando o Quartus
- Introdução à linguagem de descrição de hardware – Verilog Parte 2
- Projeto: circuito decodificador BCD para display 7 segmentos em verilog
- Projeto contador crescente síncrono/assíncrono em verilog
- Projeto divisor de frequência em verilog
- Projeto multiplexador em verilog
- Projeto de uma ULA em verilog
- Máquina de estados para um contador crescente/decrescente em verilog
