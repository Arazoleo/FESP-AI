## Ementa

Introdução à linguagem Python e ao uso de bibliotecas de BioPython. Métodos de Alinhamento de Sequências simples (Needleman-Wunsch, Smith-Waterman, BLAST). Métodos de alinhamentos múltiplos. Modelos de Markov escondidos. Análise de Clusters. Análise de Componentes Principais. Métodos de sequenciamento, montagem e análise de genomas.

### Tópicos

- Introdução à linguagem Python e ao uso de bibliotecas de BioPython
- Métodos de Alinhamento de Sequências simples (Needleman-Wunsch, Smith-Waterman, BLAST)
- Métodos de alinhamentos múltiplos
- Modelos de Markov escondidos
- Análise de Clusters
