## Ementa

Estimação pontual e intervalar. Teste de hipóteses. Regressão linear simples. Regressão linear múltipla.

### Tópicos

**1. Inferência**
- Estimação pontual: métodos de estimação (momentos, máxima verossimilhança, mínimos quadrados, bayesiana) e métodos de avaliação dos estimadores
- Estimação intervalar (uma população): para a média de uma distribuição normal; para a variância de uma distribuição normal; para a proporção
- Estimação intervalar (duas populações): para a diferença de médias; para a razão de variâncias; para a diferença de proporções
- Método bootstrap para intervalos de confiança para a média
- Intervalo de credibilidade para a média (estimação bayesiana)
- Testes de hipóteses para os parâmetros e não paramétricos: soma de postos de Wilcoxon e Kruskal-Wallis

**2. Regressão Linear Simples**
- Modelo estatístico
- Estimação dos parâmetros do modelo
- Intervalos de confiança para os parâmetros, respostas médias e previsões para novas observações
- Testes de hipóteses para os parâmetros
- Verificação das suposições do modelo
- Análise de pontos influentes
- Representação matricial

**3. Regressão Linear Múltipla**
- Modelo estatístico
- Modelo polinomial para dados sem e com replicação
- Estimação matricial dos parâmetros do modelo
- Testes de hipóteses para os coeficientes individuais e subconjuntos de coeficientes
- Intervalos de confiança para os coeficientes, respostas médias e previsões
- Verificação das suposições do modelo
- Análise de pontos influentes
- Variáveis indicadoras
- Seleção de variáveis
- Multicolinearidade
