# Introdução ao Desenvolvimento de Sistemas de Software

**Código:** MAC0350  
**Curso(s):** Bacharelado em Ciência da Computação (USP - IME)  
**Termo:** 5  
**Formato:** Disciplina  

## Pré-requisitos

- Algoritmos e Estruturas de Dados I (Código: MAC0121)
- Técnicas de Programação I (Código: MAC0216)

## Ementa

Boas práticas para desenvolvimento de software colaborativo e ferramentas de gestão de projetos. Orientação a objetos: encapsulamento, herança, polimorfismo, interfaces, exceções. Arcabouços para sistemas web ou aplicativos móveis. Coleta de requisitos, modelagem, projeto e implementação. Técnicas avançadas de teste e automatização. Refatoração. Introdução a padrões de projeto. Persistência de dados: projeto conceitual, lógico e físico de bancos; normalização. Modelo entidade-relacionamento e relacional: álgebra e cálculo relacional e SQL.
