# Algoritmos e Estruturas de Dados II

**Código:** MAC0323  
**Curso(s):** Bacharelado em Ciência da Computação (USP - IME)  
**Termo:** 3  
**Formato:** Disciplina  

## Pré-requisitos

- Algoritmos e Estruturas de Dados I (Código: MAC0121)

## Ementa

Tipos abstratos de dados e suas implementações. Análise de complexidade de tempo e espaço (pior caso, caso médio, análise amortizada). Tabelas de símbolos: árvores de busca balanceadas, hashing, tries ternárias. Grafos: busca em profundidade e largura, caminhos mínimos (Dijkstra), ordenação topológica, componentes fortes. Processamento de texto: expressões regulares e autômatos, busca de padrões (KMP, Rabin-Karp), compressão (Huffman), vetores de sufixos. Tópicos opcionais: árvores B, LZW, gerenciamento de memória.
